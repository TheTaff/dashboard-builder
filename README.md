# Интерактивный конструктор дашборда

Одностраничное веб-приложение (SPA) для создания и настройки пользовательского дашборда с карточками-виджетами. Выполнено в рамках лабораторной работы по фронтенд-разработке на чистом стеке (Vanilla JS, HTML5, CSS3) без использования сторонних библиотек и фреймворков.

## Реализованный функционал

* **Управление дашбордом:** добавление новых виджетов, полный сброс состояния (через кастомное модальное окно подтверждения), счётчик активных карточек и переключение светлой/тёмной темы.
* **4 типа виджетов:**
  * **Заметка:** текстовый блок с переходом в режим редактирования (`textarea`) по двойному клику.
  * **Счётчик:** инкремент/декремент значения с настраиваемым шагом.
  * **Список задач (To-Do):** добавление, удаление, отметка выполненных задач и подсчёт прогресса.
  * **Столбчатый график:** отрисовка на нативном `<canvas>` с учётом `devicePixelRatio` и текущей цветовой темы.
* **Общие функции карточек:** переименование заголовка по двойному клику или кнопке, сворачивание/разворачивание содержимого, удаление.
* **Drag-and-Drop:** перетаскивание карточек для изменения их порядка на нативных событиях (`dragstart`, `dragover`, `drop`, `dragend`) + базовая поддержка тач-экранов (`touchstart`, `touchmove`, `touchend`) за ручку перетаскивания.
* **Адаптивная сетка:** CSS Grid раскладка (3 колонки на десктопе, 2 на планшете, 1 на мобильных устройствах).
* **Работа с `localStorage`:** автоматическое сохранение состояния (виджеты, порядок, тема) и версионирование схемы данных (`version: 2`) с защитой от повреждённого JSON через `try...catch` и безопасным сбросом.
* **Асинхронность:** имитация загрузки данных графика через `Promise` + `setTimeout` (500–1000 мс) со спиннером загрузки и обработкой случайной ошибки сети (кнопка «Повторить»).
* **Доступность и UX:** кастомные модальные окна с поддержкой Focus Trap (удержание фокуса внутри окна по `Tab`), закрытием по `Esc` и клику на фон, блокировкой скролла страницы, валидацией пустых полей и всплывающими Toast-уведомлениями (автоскрытие через 3 секунды).
